```ts
import { Effect, Schema } from "effect";
import { ArrondissementFromPcode, CameroonLocations } from "cameroon-locations/effect";

const Form = Schema.Struct({ commune: ArrondissementFromPcode });
const { commune } = Schema.decodeUnknownSync(Form)({ commune: "CM002007001" });
commune.name.fr; // "Yaoundé I"

const program = Effect.gen(function* () {
  const locations = yield* CameroonLocations;
  const region = yield* locations.getRegion("Littoral");
  return `${commune.name.fr}, ${region.name.en}`;
}).pipe(Effect.catchTag("LocationNotFound", (e) => Effect.succeed(e.message)));

Effect.runSync(program.pipe(Effect.provide(CameroonLocations.layer)));
// "Yaoundé I, Littoral"
```

## When to use it

- **Use the core** (`cameroon-locations`) for plain lookups. It returns
  `T | undefined`, never throws and has no dependencies.
- **Use `/effect`** to validate untrusted input (form values, route params,
  API payloads, JSON from storage) and when you want typed errors in the
  error channel instead of `undefined` checks.

Both read the same frozen records; you can mix them.

## Decoding P-codes

The `*FromPcode` schemas decode a P-code string into its record and encode
the record back to the P-code, so a form or API field can hold the stable
code while your code works with the full record. Unknown codes fail.

```ts
import { Schema } from "effect";
import {
  AdminUnitFromPcode,
  ArrondissementFromPcode,
  DivisionFromPcode,
  RegionFromPcode,
} from "cameroon-locations/effect";

Schema.decodeUnknownSync(RegionFromPcode)("CM002").name.en; // "Centre"
Schema.decodeUnknownSync(DivisionFromPcode)("CM002007").name.fr; // "Mfoundi"
Schema.decodeUnknownSync(AdminUnitFromPcode)("CM002007").level; // "division"

const Form = Schema.Struct({ commune: ArrondissementFromPcode });
Schema.decodeUnknownSync(Form)({ commune: "CM002007999" });
// throws SchemaError: Unknown arrondissement P-code "CM002007999" at ["commune"]
Schema.decodeUnknownSync(Form)({ commune: "Yaoundé I" });
// throws SchemaError: Expected an arrondissement P-code such as CM002007001
```

Encoding gives back the code, ready to store or send:

```ts
Schema.encodeSync(Form)({ commune }); // { commune: "CM002007001" }
```

## Schemas

Every type of the [data model](/docs/data-model) has a schema. Record
schemas check the shape, not that the unit exists; use the `*FromPcode`
decoders for that.

| Schema | Validates |
| :----- | :-------- |
| `Pcode` | Any P-code: `CM001`, `CM001001` or `CM001001001` |
| `RegionPcode`, `DivisionPcode`, `ArrondissementPcode` | A P-code of one level |
| `AdminLevel`, `Language`, `SourceId` | The literal unions |
| `LocalizedName`, `Alias`, `Population`, `LngLat`, `BBox` | Building blocks |
| `Region`, `Division`, `Arrondissement` | Administrative unit records |
| `AdminUnit` | Union of the three, tagged on `level` |
| `Canton`, `Village` | BUCREP records |

```ts
import { Schema } from "effect";
import { AdminUnit, Pcode, Region, RegionPcode } from "cameroon-locations/effect";

Schema.decodeUnknownSync(Pcode)("CM004"); // "CM004"
Schema.is(RegionPcode)("CM002007"); // false
Schema.decodeUnknownSync(Region)(JSON.parse(cached)); // a Region, or throws
```

`AdminUnit` comes with the tagged-union helpers `AdminUnit.match` and
`AdminUnit.guards`:

```ts
const unit = Schema.decodeUnknownSync(AdminUnit)(payload);

AdminUnit.match(unit, {
  region: (r) => r.name.en,
  division: (d) => `division in ${d.regionPcode}`,
  arrondissement: (a) => a.divisionPcode,
});

if (AdminUnit.guards.division(unit)) unit.regionPcode;
```

## Lookups

The name-based lookups accept the same [queries](/docs/lookups#queries) as
the core (P-code, HASC code or any name or alias) and return an `Effect`
that fails with a tagged error.

```ts
function getRegion(query: LocationQuery): Effect<Region, LookupError>;
function getDivision(query: LocationQuery, options?: { within?: Pcode }): Effect<Division, LookupError>;
function getArrondissement(query: LocationQuery, options?: { within?: Pcode }): Effect<Arrondissement, LookupError>;
function getUnit(pcode: Pcode): Effect<AdminUnit, LocationNotFound>;
```

```ts
import { Effect } from "effect";
import { getArrondissement, getRegion } from "cameroon-locations/effect";

Effect.runSync(getRegion("Littoral")).pcode; // "CM005"
Effect.runSync(getArrondissement("Yaoundé 1er", { within: "CM002007" })).pcode;
// "CM002007001"

getRegion("Atlantis").pipe(
  Effect.map((r) => r.pcode),
  Effect.catchTag("LocationNotFound", (e) => Effect.succeed(e.message)),
); // succeeds with 'No region matches "Atlantis"'
```

### Errors

<PropsTable
  label="Error"
  rows={[
    { name: "LocationNotFound", type: "{ query: string; level?: AdminLevel }", description: "Nothing matches the query at that level. level is absent for getUnit, which accepts every level." },
    { name: "AmbiguousLocation", type: "{ query: string; level: AdminLevel; candidates: readonly Pcode[] }", description: "Several units at the level carry the name. Retry with one of the candidate P-codes, or narrow with within." },
  ]}
/>

`LookupError` is `LocationNotFound | AmbiguousLocation`. No name is shared
within a level in the current data, but aliases may collide as sources are
added, so handle both:

```ts
getArrondissement(input, { within: divisionPcode }).pipe(
  Effect.catchTags({
    LocationNotFound: () => Effect.succeed(undefined),
    AmbiguousLocation: (e) => Effect.fail(new Error(`pick one of ${e.candidates.join(", ")}`)),
  }),
);
```

### Option variants

`getRegionOption`, `getDivisionOption`, `getArrondissementOption` and
`getUnitOption` return an `Option`: `None` when nothing matches or the name is
ambiguous.

```ts
import { Option } from "effect";
import { getArrondissementOption, getRegionOption } from "cameroon-locations/effect";

Option.map(getRegionOption("Centre"), (r) => r.pcode); // Some("CM002")
getArrondissementOption("nowhere"); // None
```

## Service

`CameroonLocations` exposes `getRegion`, `getDivision`, `getArrondissement`
and `getUnit` as a service, so your code can depend on it through the context
and tests can swap in a stub. `CameroonLocations.layer` provides the dataset
bundled with the package.

```ts
import { Effect, Layer } from "effect";
import { regions } from "cameroon-locations";
import { CameroonLocations } from "cameroon-locations/effect";

const program = Effect.gen(function* () {
  const locations = yield* CameroonLocations;
  return (yield* locations.getRegion("Littoral")).name.fr;
});

Effect.runSync(program.pipe(Effect.provide(CameroonLocations.layer))); // "Littoral"

// In tests
const Stub = Layer.succeed(
  CameroonLocations,
  CameroonLocations.of({
    getRegion: () => Effect.succeed(regions[4]!),
    getDivision: () => Effect.die("unused"),
    getArrondissement: () => Effect.die("unused"),
    getUnit: () => Effect.die("unused"),
  }),
);
```
