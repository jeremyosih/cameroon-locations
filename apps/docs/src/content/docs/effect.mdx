The adapter wraps the same data and lookups with:

- **Schemas** for every record type (`Region`, `Division`, `Arrondissement`,
  `Canton`, `Village`, …), to decode and validate P-codes and records at your
  boundaries.
- **`Option` lookups** instead of `T | undefined`.
- **Tagged errors** for effectful variants that fail when nothing matches.

`effect` is an optional peer dependency (version 4); the rest of the package
never imports it.
