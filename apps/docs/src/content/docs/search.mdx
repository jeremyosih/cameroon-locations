## search

```ts
function search(query: string, options?: SearchOptions): readonly SearchResult[];
```

Ranks regions, divisions and arrondissements against the query. Every name
and alias counts, in both languages, so "far north", "extreme nord" and
"Extrême-Nord" find the same region, and "yaounde 1er" finds "Yaoundé I".

```ts
import { search } from "cameroon-locations/search";

const [best] = search("bamenda");
best?.item.name.fr; // "Bamenda I", …
best?.score; // 0..1
best?.matched; // the name or alias that matched

search("douala", { levels: ["arrondissement"], limit: 3 });
search("mbalmayo", { within: "CM002" }); // only in Centre
```

Each result is:

```ts
interface SearchResult<T = AdminUnit> {
  item: T;
  score: number; // 0 (worst) to 1 (exact)
  matched: string; // the name or alias that matched
}
```

Results are sorted by score. Exact matches (after
[`normalizeName`](/docs/lookups#normalizename)) score 1.

## createSearch

```ts
function createSearch<T>(
  items: readonly T[],
  names: (item: T) => readonly string[],
): (query: string, options?: { limit?: number }) => readonly SearchResult<T>[];
```

Builds the same search over any records. The index is built once, when you
call `createSearch`; keep the returned function around.

```ts
import { createSearch } from "cameroon-locations/search";
import { cantons } from "cameroon-locations/cantons";

const searchCantons = createSearch(cantons, (c) => [c.label, c.name]);
searchCantons("lamidat", { limit: 5 });
```

It works on your own data too:

```ts
const searchShops = createSearch(shops, (s) => [s.name, s.neighbourhood]);
```

## Tips

- For exact matching of known names (imports, CSV joins), prefer
  [`find`](/docs/lookups#find) or the `get*` lookups. `search` is for people
  typing.
- To build a picker that drills down region → division → arrondissement,
  combine `search` with `within`, or use the
  [Location picker](/docs/location-picker) component.
