## Installation

<InstallCommand client:load shadcn={registryUrl("cameroon-map")} />

The map uses Leaflet and react-leaflet, with the `cameroon-locations` npm
package for the boundaries: the GeoJSON is too large to copy into your
source. The command adds `components/cameroon-map.tsx`,
`components/cameroon-map-leaflet.tsx` (the map, base map tiles, a layers menu
and zoom and fullscreen controls), `components/cameroon-map-scale.ts`, the
Leaflet styles and five `--choropleth-*` colours to your CSS. It only needs
the stock `button` and `button-group` components.

The Leaflet building blocks are adapted from
[shadcn-map](https://github.com/tonghohin/shadcn-map) (MIT).

## Usage

```tsx
import { CameroonMap } from "@/components/cameroon-map";

<CameroonMap
  level="division"
  selected={pcode}
  onSelect={(unit) => setPcode(unit.pcode)}
/>;
```

Shapes are keyed by P-code, like the rest of the package, and `onSelect`
receives the record (`Region`, `Division` or `Arrondissement`). Only the
GeoJSON file for the level and `detail` shown is downloaded: each one is a
separate dynamic import, so bundlers split them.

The boundary attribution from `attribution()` is always shown in the map's
attribution control, as the OCHA licence requires. Add the sources of your
own data with `sources`, for example
`sources={["bucrep-rgph2005-repertoire-villages"]}` for census figures. See
[Metadata & attribution](/docs/metadata).

Add base maps with `MapTileLayer` and overlays with `MapLayerGroup` from
`cameroon-map-leaflet`, as children. With more than one base map, or any
overlay, a layers menu appears under the zoom buttons, as in the map above.
It opens inside the map, so it also works in fullscreen.

```tsx
import { MapLayerGroup, MapTileLayer } from "@/components/cameroon-map-leaflet";

<CameroonMap fullscreen>
  <MapTileLayer
    name="OpenStreetMap"
    rasterUrl="https://tile.openstreetmap.org/{z}/{x}/{y}.png"
    rasterAttribution="&copy; OpenStreetMap"
  />
  <MapLayerGroup name="Offices">{/* react-leaflet markers */}</MapLayerGroup>
</CameroonMap>;
```

## Examples

### Choropleth

Pass `values` keyed by P-code and the map colours each unit on a five-class
sequential scale, with a legend and the value in the tooltip. Classes are
quantiles by default, so skewed data such as population still uses every
colour; `scale="linear"` splits the range into equal steps instead. Units
without a value are drawn in grey.

This one maps population density from the 2005 census
(`population2005.total / areaSqKm`). Density, rather than the raw count, is
what a choropleth should show: large units would otherwise look important
because they are large.

The colours are CSS variables, one blue hue from light to dark, with the
dark theme reversed so low values recede into the background. Change them
in your CSS:

```css
:root {
  --choropleth-1: #b7d3f6;
  --choropleth-2: #6da7ec;
  --choropleth-3: #2a78d6;
  --choropleth-4: #184f95;
  --choropleth-5: #0d366b;
}
.dark {
  --choropleth-1: #0d366b;
  --choropleth-2: #1c5cab;
  --choropleth-3: #3987e5;
  --choropleth-4: #86b6ef;
  --choropleth-5: #cde2fb;
}
```

### Drill-down

With `drillDown`, clicking a region shows its divisions, and a division its
arrondissements, with a back control. A `selected` P-code from elsewhere
moves the map the same way, so here a
[location picker](/docs/location-picker) and the map share one state.

### Click to locate

Shapes report the unit you click. To get the arrondissement under any
point, whatever level is shown, pass a react-leaflet click handler as a
child and call [`locate`](/docs/geo#locate) (see the
[Locate a point](/docs/geo#locate-a-point) demo):

```tsx
import type { Pcode } from "cameroon-locations";
import { locate } from "cameroon-locations/geo";
import { useMapEvents } from "react-leaflet";

function ClickToLocate({ onLocate }: { onLocate: (pcode: Pcode | null) => void }) {
  useMapEvents({
    click: ({ latlng }) => onLocate(locate([latlng.lng, latlng.lat])?.pcode ?? null),
  });
  return null;
}

<CameroonMap level="region" selected={pcode}>
  <ClickToLocate onLocate={setPcode} />
</CameroonMap>;
```

`selected` can be an arrondissement while regions are shown: the region
containing it is outlined and the map zooms to the arrondissement.

## Accessibility

- Every unit is focusable and announced as a button with its name; Tab
  moves between units, Enter or Space selects, and focus shows the tooltip.
- The legend lists every class range for screen readers.
- The scale is one hue that only changes lightness, readable with colour
  vision deficiencies. For exact figures, pair the map with a table.
