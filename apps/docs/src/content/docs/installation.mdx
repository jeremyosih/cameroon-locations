## Install from npm

<InstallCommand client:load />

The package ships ESM and CommonJS builds with type declarations, has no
runtime dependencies and needs Node 20.19 or later (or any modern bundler,
Bun or Deno). `cameroon-locations/effect` is ESM-only, like `effect` itself:
import it from an ES module.

```ts
import { getRegion, regions } from "cameroon-locations";

regions.length; // 10
getRegion("Far-North")?.pcode; // "CM004"
```

## Entry points

Each dataset lives behind its own import, so you only ship what you use.
The root import holds the 428 administrative units and stays small.

| Import                         | Contents                                                                          |
| :----------------------------- | :-------------------------------------------------------------------------------- |
| `cameroon-locations`           | Regions, divisions, arrondissements, lookups, `normalizeName`, `metadata`, `sources`, `attribution()` |
| `cameroon-locations/cantons`   | 1,504 cantons, `getCanton`, `getCantons`, `findCantons`                           |
| `cameroon-locations/villages`  | 17,070 villages, `getVillage`, `getVillages`, `findVillages`                      |
| `cameroon-locations/search`    | `search`, `createSearch`                                                          |
| `cameroon-locations/geo`       | `locate`, `nearest`, `distanceKm`                                                 |
| `cameroon-locations/elecam`    | Polling stations and council summaries (July 2025)                                |
| `cameroon-locations/effect`    | Effect schemas, `Option` lookups and tagged errors (optional `effect` peer)       |
| `cameroon-locations/geojson/*` | Simplified OCHA boundaries as GeoJSON files                                       |

```ts
import { getCantons } from "cameroon-locations/cantons";
import { search } from "cameroon-locations/search";
import { locate } from "cameroon-locations/geo";
```

### Effect

The Effect adapter needs `effect` 4 as a peer dependency. Everything else
works without it.

## Copy and paste with shadcn

If you'd rather own the code, the core (types, sources, `normalizeName`,
lookups and search, with the administrative data inlined) is published as a
[shadcn](https://ui.shadcn.com) registry item. It adds plain TypeScript files
to `lib/cameroon-locations/` and no npm dependency.

<InstallCommand client:load shadcn={registryUrl("cameroon-locations-core")} />

```ts
import { getRegion } from "@/lib/cameroon-locations/lookup";
import { search } from "@/lib/cameroon-locations/search";
```

The copied files don't include cantons, villages, GeoJSON or ELECAM data;
install the package for those. Keep the attribution: the
[sources](/docs/metadata) ship in `sources.ts`.

## TypeScript

Types are included. The data model is documented in
[Data model](/docs/data-model); import the types with `import type`:

```ts
import type { Arrondissement, Pcode } from "cameroon-locations";
```
