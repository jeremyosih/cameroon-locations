## attribution

```ts
function attribution(ids?: readonly SourceId[]): string;
```

One paragraph suitable for a map footer or an "about" page. It defaults to
the OCHA boundaries credit; pass the sources you actually display.

```ts
import { attribution } from "cameroon-locations";

attribution();
attribution(["ocha-cod-ab-cmr", "bucrep-rgph2005-repertoire-villages"]);
```

The output below is produced by the package while this page is built:

<AttributionExample />
<AttributionExample ids={["ocha-cod-ab-cmr", "bucrep-rgph2005-repertoire-villages"]} />

Every record carries `sources`, so you can build the credit from what you
show:

```ts
import { attribution, getArrondissements } from "cameroon-locations";

const shown = getArrondissements("Mfoundi");
const credit = attribution(shown.flatMap((a) => a.sources));
```

## sources

```ts
const sources: Readonly<Record<SourceId, SourceInfo>>;
function getSources(ids: readonly SourceId[]): readonly SourceInfo[];
```

The source registry: title, publisher, licence, where it is published online
and the archived copy in this repository. `getSources` returns records for the
given ids, in order, without duplicates, as a frozen array; unknown ids are
skipped (and `attribution` skips them too).

```ts
import { getSources, sources } from "cameroon-locations";

sources["ocha-cod-ab-cmr"].license; // "CC BY-IGO 3.0"
getSources(["wikidata"])[0]?.url; // "https://www.wikidata.org"
```

## metadata

```ts
const metadata: DatasetMetadata;

interface DatasetMetadata {
  name: string; // "cameroon-locations"
  version: string; // data version, e.g. "2026.10.17+a9b6a49f"
  generated: string; // date of the data build, e.g. "2026-10-17"
  repository: string;
  sources: readonly SourceInfo[];
}
```

`metadata` describes the bundled dataset as a whole. Records don't carry it;
each record lists its own `sources` instead.

The GeoJSON files have their own top-level `metadata` member, with a
different shape: `name`, `version` and `generated` (the dataset version
and date the files were built from, in the same format as `metadata` above;
they are regenerated separately, so they can lag behind it), `repository`, a `license` note, the boundary
`attribution`, a `notice` link to NOTICE.md, `sources` (the OCHA record
only), and the file's `level` (`levels` in `cameroon.topo.json`),
`detail` and `simplification`.
