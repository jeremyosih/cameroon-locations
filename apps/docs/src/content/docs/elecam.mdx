Every arrondissement is one commune (council). ELECAM publishes the roll by
council, polling centre and station; each council is linked to its
arrondissement P-code, so you can join it with everything else. Stations
abroad (diaspora) have `arrondissementPcode: null`.

<Callout title="A snapshot">
  The figures come from a CSV of the 2025 roll dated 24 July 2025, probably
  the July 2025 provisional roll; where it was downloaded from was not
  recorded. ELECAM publishes the official polling-station lists as PDFs on
  [its portal](https://portail.elecam.cm/fr/documentation/); the final roll
  of October 2025 is larger (about 8.0 million voters). The figures are not
  updated live.
</Callout>

## getCouncilSummary

```ts
function getCouncilSummary(arrondissementPcode: Pcode): CouncilElectoralSummary | undefined;
```

Totals for one arrondissement's council.

```ts
const s = getCouncilSummary("CM002007001");
s?.council; // "YAOUNDE I", as printed by ELECAM
s?.registeredVoters; // 117438
s?.pollingCentres; // 76
s?.pollingStations; // 368
```

## getPollingStations

```ts
function getPollingStations(within: Pcode | null): readonly PollingStation[];
```

Stations in an arrondissement, division or region, by P-code (case and
surrounding whitespace ignored). `null` returns the diaspora stations.
Anything that is not a P-code, such as a name or a partial code like
`"CM00"`, returns an empty array.

```ts
getPollingStations("CM002007").length; // 2297, every station in Mfoundi
getPollingStations(null).length; // 95, abroad

const voters = getPollingStations("CM005").reduce(
  (sum, s) => sum + s.registeredVoters,
  0,
); // 1275475 in Littoral
```

## Datasets

```ts
pollingStations; // readonly PollingStation[], 30,353
councilSummaries; // readonly CouncilElectoralSummary[], one per arrondissement
```

## How councils are matched

ELECAM council names are matched to arrondissements by normalised name within
the right division, plus 39 manual decisions: 36 councils (most of them
communes named after their chef-lieu), 2 division spellings
("VALLE DU NTEM", "KOUPE-MANENGOUBA") and the diaspora entry
("CMR A L'ETRANGER", kept with no P-code). Each decision is recorded with
its evidence in `data/crosswalks/elecam-codab.json`. Credit the source with
`attribution(["elecam-polling-stations-2025"])`.
