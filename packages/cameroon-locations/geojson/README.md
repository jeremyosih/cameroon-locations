# GeoJSON

Simplified OCHA COD-AB boundaries of Cameroon, generated by
`bun run data:geo` (`scripts/geo.ts`). Do not edit by hand.

| File | Level | Detail | Size |
|---|---|---|---|
| `arrondissements.geo.json` | arrondissement | default | 393 KB |
| `arrondissements.high.geo.json` | arrondissement | high | 924 KB |
| `arrondissements.low.geo.json` | arrondissement | low | 157 KB |
| `cameroon.topo.json` | all four, shared arcs | default | 200 KB |
| `country.geo.json` | country | default | 28 KB |
| `country.high.geo.json` | country | high | 78 KB |
| `country.low.geo.json` | country | low | 6 KB |
| `divisions.geo.json` | division | default | 156 KB |
| `divisions.high.geo.json` | division | high | 426 KB |
| `divisions.low.geo.json` | division | low | 42 KB |
| `regions.geo.json` | region | default | 73 KB |
| `regions.high.geo.json` | region | high | 207 KB |
| `regions.low.geo.json` | region | low | 16 KB |

- Detail: Visvalingam (weighted) simplification with topology preserved
  (low 4000 m, default 700 m, high 220 m). All levels are dissolved from the same simplified
  arrondissements, so borders nest and match exactly. Use `low` for
  overview maps and small screens, the default up to about zoom 9, `high`
  when zoomed in to a city.
- GeoJSON follows RFC 7946: WGS 84 longitude/latitude, counter-clockwise
  outer rings, coordinates rounded to 5 decimals (4 in `low` files, about
  11 m). d3-geo expects the opposite winding; d3 users should prefer
  `cameroon.topo.json` (objects `country`, `regions`, `divisions`, `arrondissements`; use
  `topojson-client`'s `feature()` / `mesh()`).
- Feature `id` is the OCHA P-code, so features join to the package's
  records with `getUnit(feature.id)`. `properties`: `pcode`, `level`,
  `name_fr`, `name_en`, `parentPcode`, plus `regionPcode` and
  `divisionPcode` where they apply.
- Each file has a top-level `metadata` member with the version, licence
  and sources (online URL and archived copy in this repository).
- Files use the `.geo.json` / `.topo.json` extensions so that Node,
  bundlers and TypeScript (`resolveJsonModule`) import them as JSON with
  no loader.

```js
import regions from "cameroon-locations/geojson/regions.geo.json" with { type: "json" };
// or fetch("https://unpkg.com/cameroon-locations/geojson/regions.geo.json")
```
