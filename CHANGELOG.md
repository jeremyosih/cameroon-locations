# Changelog

Release notes for the `cameroon-locations` package live in
[`packages/cameroon-locations/CHANGELOG.md`](packages/cameroon-locations/CHANGELOG.md)
and are generated by Changesets from the first release on.

Versions up to 0.1.x were the July 2025 export forked from
[kenya-locations](https://github.com/DavidAmunga/kenya-locations). Their data
defects are documented in
[`data/derived/location-script-2025-07/NOTES.md`](data/derived/location-script-2025-07/NOTES.md).
